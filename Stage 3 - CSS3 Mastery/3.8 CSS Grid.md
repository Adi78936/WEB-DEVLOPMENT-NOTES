# 3.8 CSS Grid

## Interview preparation

CSS Grid is a two-dimensional layout system. It arranges items in rows and columns and is well suited to page layouts, dashboards, galleries, and responsive card grids.

## Grid container and items

```css
.dashboard {
  display: grid;
}
```

The element with `display: grid` is the grid container; its in-flow children are grid items. Grid can explicitly define tracks or create them automatically.

## Columns and rows

```css
.layout {
  display: grid;
  grid-template-columns: 15rem 1fr;
  grid-template-rows: auto 1fr auto;
}
```

`grid-template-columns` and `grid-template-rows` define explicit tracks. `grid-auto-columns` and `grid-auto-rows` affect implicit tracks created by automatic placement.

## Gaps and fractional units

```css
.cards {
  display: grid;
  grid-template-columns: 1fr 2fr;
  gap: 1rem;
}
```

- `gap`, `row-gap`, and `column-gap` create gutters between tracks.
- `fr` represents a fraction of available free space after other track sizes and gaps are accounted for.
- A grid track's `minmax()` constraints and the content-minimum sizing rules can affect how space is allocated.

## `repeat()` and `minmax()`

```css
.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 1rem;
}
```

- `repeat(3, ...)` repeats a track definition.
- `minmax(min, max)` sets a track's minimum and maximum sizing constraints.
- `minmax(0, 1fr)` allows tracks to shrink below their automatic min-content minimum, useful when content would otherwise force overflow.

## `auto-fit` and `auto-fill`

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(14rem, 1fr));
  gap: 1rem;
}
```

- `auto-fill` creates as many tracks as fit, preserving empty tracks.
- `auto-fit` also creates fitting tracks but collapses empty tracks so occupied tracks can expand.
- They are particularly useful for responsive grids without a media query for every column count.

## Grid template areas

```css
.page {
  display: grid;
  grid-template-columns: 14rem 1fr;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}
.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }
```

Named areas communicate the layout visually in CSS. Each named area must form a rectangular region in the grid.

## Item placement: rows and columns

```css
.featured {
  grid-column: 1 / 3;
  grid-row: 1 / span 2;
}
```

Lines can be numbered or named. `span` expresses how many tracks an item occupies. Placement can be explicit or automatic. Overlapping items are possible, but use them intentionally.

## Nested grids

A grid item can itself become a grid container:

```css
.dashboard { display: grid; grid-template-columns: 1fr 1fr; }
.dashboard-panel { display: grid; grid-template-rows: auto 1fr; }
```

Nested grids have their own tracks. For some shared alignment use cases, CSS subgrid can allow a nested grid to participate in parent tracks where supported.

## Grid vs. Flexbox

- Use Grid for two-dimensional relationships (rows and columns).
- Use Flexbox for a one-dimensional row or column and distribution along one primary axis.
- They can be combined; choose based on the layout problem rather than treating them as competitors.

## Interview review

1. What makes Grid two-dimensional? It controls rows and columns together.
2. What is an `fr` unit? A share of available free space in a grid track.
3. How do `auto-fit` and `auto-fill` differ? `auto-fit` collapses empty repeated tracks; `auto-fill` preserves them.
4. What does `minmax(0, 1fr)` help with? It permits a track to shrink below its content-based automatic minimum.
5. When choose Grid over Flexbox? When the layout has meaningful row and column relationships rather than primarily one axis.
6. What is an implicit grid track? A track created automatically when placement needs a row or column not defined explicitly.

## Good practices

- Use `gap` rather than per-item margins for grid gutters.
- Use `minmax()` for robust responsive sizing.
- Check long words and intrinsic image sizes for overflow.
- Use named areas when they make a page layout easier to understand.
- Preserve logical reading order when using explicit placement.
