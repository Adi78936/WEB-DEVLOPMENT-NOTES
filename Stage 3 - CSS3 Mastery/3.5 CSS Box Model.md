# 3.5 CSS Box Model

## Interview preparation

Every CSS element is represented by a rectangular box. The standard box model consists, from inside to outside, of **content**, **padding**, **border**, and **margin**.

```text
margin
  border
    padding
      content
```

## Content, width, and height

With the default `content-box`, declared width and height apply to the content box:

```css
.card { width: 300px; padding: 20px; border: 2px solid; }
```

Its outer width is `300 + 40 + 4 = 344px`, excluding margins.

## Padding

Padding is the space between content and border. It is part of the element's background painting area and cannot be negative.

```css
.card { padding: 1rem 1.5rem; }
```

## Border

The border surrounds the padding and content:

```css
.card { border: 1px solid #d5d9d4; }
```

## Margin

Margin is external spacing around the border. Margins can be negative, and vertical margins between normal-flow block boxes may collapse.

```css
.section { margin-block: 2rem; }
```

## `box-sizing`

```css
*, *::before, *::after { box-sizing: border-box; }
```

- `content-box`: `width`/`height` apply to content only.
- `border-box`: declared dimensions include content, padding, and border.
- A global `border-box` baseline makes many layouts easier to reason about; margins remain outside the specified dimensions.

## Minimum and maximum dimensions

```css
.content {
  width: 100%;
  min-width: 0;
  max-width: 70rem;
  min-height: 12rem;
}
```

`min-width`, `max-width`, `min-height`, and `max-height` constrain the used size. In flex and grid layouts, a default min-content size can sometimes prevent an item from shrinking; `min-width: 0` is a common targeted fix.

## Margin collapse

In certain normal-flow block formatting contexts, adjacent vertical margins collapse into one margin rather than adding together. This can occur between sibling blocks and between a parent and its first/last child under specified conditions.

Margins generally do not collapse:

- Horizontally.
- Inside flex or grid layout items in the same way as normal-flow blocks.
- When borders, padding, inline content, or a new formatting context separate them.

Do not assume `margin-top + margin-bottom` is the visible gap. Inspect layout or use `gap` in flex/grid layouts when spacing between items is intended.

## Overflow

`overflow` controls content extending outside a box:

```css
.table-wrapper { overflow-x: auto; }
```

Common values:

- `visible`: content can extend beyond the box.
- `hidden`: clips overflow.
- `clip`: clips without creating a scroll container.
- `auto`: adds scrolling when needed.
- `scroll`: provides a scroll mechanism even if not needed, depending on platform.

Be cautious with `overflow: hidden`; it can clip focus indicators, menus, or content and can change scrolling behavior.

## Outline

An outline is drawn outside an element's border and generally does not affect layout:

```css
button:focus-visible { outline: 3px solid #d76b46; outline-offset: 3px; }
```

Outlines are useful for focus indication. Do not remove focus outlines unless a clearly visible replacement is supplied.

## Interview review

1. What are the box-model layers? Content, padding, border, and margin.
2. How does `border-box` change width calculation? The declared width includes padding and border.
3. Do margins contribute to the width under `border-box`? No.
4. What is margin collapse? Certain adjacent vertical block margins combine rather than sum.
5. How does outline differ from border? Outline is outside the border and normally does not take up layout space.

## Good practices

- Use `box-sizing: border-box` as a predictable baseline.
- Use padding for internal breathing room and margin or `gap` for external spacing.
- Check overflow when content or focus indicators disappear.
- Prefer `gap` for spacing between flex/grid children.
- Avoid fixed heights for content that may wrap or grow.
