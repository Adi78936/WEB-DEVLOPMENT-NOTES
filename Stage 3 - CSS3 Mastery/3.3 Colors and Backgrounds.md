# 3.3 Colors and Backgrounds

## CSS color formats

CSS supports several ways to represent colors.

### Named colors

```css
color: tomato;
```

Named colors are convenient for examples, but a small design system usually benefits from intentional reusable values.

### HEX

```css
color: #285d4b;
color: #285d4b80; /* alpha channel in modern CSS */
```

HEX uses hexadecimal channel values; the common six-digit form is red, green, blue. Eight digits add alpha transparency.

### RGB and RGBA

```css
color: rgb(40 93 75);
color: rgb(40 93 75 / 50%);
```

RGB specifies red, green, and blue channels. Modern syntax can add an alpha value after `/`; older syntax used `rgba(...)`.

### HSL and HSLA

```css
color: hsl(157 40% 26%);
color: hsl(157 40% 26% / 70%);
```

HSL represents hue, saturation, and lightness. It can make some color adjustments more intuitive. Modern CSS allows alpha with `/`; `hsla(...)` is the older function spelling.

## Foreground and background color

`color` sets text/foreground color. `background-color` paints an element's background:

```css
.notice {
  color: #20302a;
  background-color: #e7f0e9;
}
```

Check text/background contrast, especially for small text and interactive controls. Do not rely on color alone to communicate status.

## Background images

```css
.hero {
  background-image: url("images/texture.png");
  background-color: #202722; /* fallback */
}
```

Background images are best for decorative imagery or visual surfaces. Use an HTML `<img>` when the image conveys content that needs alternative text.

## Repeating, positioning, and sizing

```css
.hero {
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}
```

- `background-repeat`: controls tiling, for example `repeat`, `repeat-x`, `repeat-y`, or `no-repeat`.
- `background-position`: positions the image, for example `center top` or `20% 50%`.
- `background-size`: `cover` fills the box and may crop; `contain` fits the full image and may leave empty space; explicit dimensions provide more control.

## Gradients

Gradients are images generated by CSS:

```css
.panel {
  background-image: linear-gradient(135deg, #244c41, #5e8b70);
}

.chart {
  background-image: radial-gradient(circle at center, #f3c58e, transparent 70%);
}
```

Common types include `linear-gradient()`, `radial-gradient()`, and `conic-gradient()`. Use gradients purposefully and ensure text remains readable over them.

## Multiple backgrounds

CSS can layer multiple background images. The first listed image is painted on top:

```css
.hero {
  background-image:
    linear-gradient(rgb(20 30 25 / 20%), rgb(20 30 25 / 75%)),
    url("images/retina.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
```

When using multiple images, comma-separated values for position, size, and repeat correspond to the background layers.

## Background shorthand

The `background` shorthand can set multiple background properties, but may reset omitted background subproperties to their initial values. Use it carefully when other background declarations should remain.

## Interview review

1. How do RGB and HSL differ? They represent colors using different coordinate systems: channels vs. hue/saturation/lightness.
2. When is a CSS background appropriate instead of `<img>`? Usually for decorative imagery that does not need content alternative text.
3. What is the difference between `cover` and `contain`? Cover fills and may crop; contain fits all image content and may leave unused space.
4. How do multiple backgrounds stack? The first listed image is on top.
5. Why not convey status only by color? Users with color-vision differences or other contexts may not distinguish the colors; include text or another cue.

## Good practices

- Define a coherent palette with custom properties.
- Provide fallback colors behind background images.
- Choose `cover` or `contain` based on whether cropping is acceptable.
- Ensure foreground/background contrast.
- Use semantic image elements for meaningful imagery.
