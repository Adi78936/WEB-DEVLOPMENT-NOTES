# 3.7 Flexbox

## Interview preparation

Flexbox is a one-dimensional layout system for arranging items along a main axis, with control over alignment and distribution along a cross axis. Use it for rows, columns, navigation, toolbars, and alignment within components.

## Flex container and items

```css
.toolbar {
  display: flex;
}
```

The element with `display: flex` is the **flex container**; its in-flow children become **flex items**.

## Main and cross axes

- `flex-direction` defines the main axis.
- The cross axis is perpendicular to the main axis.
- With `row`, main is inline/horizontal in the usual writing mode.
- With `column`, main is vertical.
- Logical writing modes can change physical directions; think in axes rather than always “left/right.”

## Direction, wrapping, and gap

```css
.layout {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap;
  gap: 1rem;
}
```

- `flex-direction`: `row`, `row-reverse`, `column`, or `column-reverse`.
- `flex-wrap`: `nowrap`, `wrap`, or `wrap-reverse`.
- `gap` sets spacing between items and lines without adding outer margins.
- Prefer logical source order; reversing visually can create confusing keyboard and reading order.

## Main-axis distribution: `justify-content`

```css
.toolbar { justify-content: space-between; }
```

Common values: `flex-start`, `flex-end`, `center`, `space-between`, `space-around`, and `space-evenly`. Modern alignment also supports logical `start` and `end` values.

## Cross-axis alignment: `align-items` and `align-self`

```css
.toolbar { align-items: center; }
.special-item { align-self: stretch; }
```

- `align-items` sets the default cross-axis alignment for flex items.
- `align-self` overrides the alignment for an individual item.
- Common values include `stretch`, `center`, `flex-start`, and `flex-end`.

## `align-content`

`align-content` distributes multiple flex lines along the cross axis when the container has extra space and wrapping has produced multiple lines. It does not generally align one single line; use `align-items` for items on a line.

## Grow, shrink, and basis

```css
.main { flex: 1 1 20rem; }
.sidebar { flex: 0 0 15rem; }
```

The `flex` shorthand is commonly described as:

```text
flex: <grow> <shrink> <basis>
```

- `flex-grow`: how an item can take a share of positive free space.
- `flex-shrink`: how it can give up space when items overflow.
- `flex-basis`: initial main-size before free space distribution.

The default `flex` is commonly `0 1 auto`. A `flex-basis` of `0` distributes space differently than `auto`.

## `order`

```css
.secondary { order: 1; }
```

`order` changes visual placement, but not DOM, keyboard, or screen-reader order. Use it carefully and do not create a mismatch between visual and logical sequence.

## Common flex sizing issue

Flex items can have a min-content-based minimum size and refuse to shrink as expected. For a flex child containing long text or an image, `min-width: 0` may allow it to shrink:

```css
.flex-child { min-width: 0; }
```

## Interview review

1. What do main and cross axes depend on? The `flex-direction`.
2. Which property distributes items on the main axis? `justify-content`.
3. Which property aligns items on the cross axis? `align-items`; `align-self` overrides an individual item.
4. When does `align-content` matter? When multiple flex lines need distribution along the cross axis.
5. What does `flex: 1` mean? A shorthand affecting grow, shrink, and basis; inspect computed values and understand the shorthand instead of assuming it means “take exactly 1 unit.”
6. Does `order` change keyboard order? No; it changes visual order only.

## Good practices

- Use Flexbox when the layout is primarily one-dimensional.
- Use `gap` for consistent spacing between items.
- Let wrapping work where appropriate instead of forcing overflow.
- Preserve meaningful DOM order.
- Use `min-width: 0` when a flex child must shrink below its min-content size.
