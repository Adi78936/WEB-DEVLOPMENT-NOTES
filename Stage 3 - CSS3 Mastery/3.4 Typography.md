# 3.4 Typography

## Interview preparation

Typography determines how text is selected, sized, spaced, and aligned. Good typography supports hierarchy, readability, accessibility, and brand identity.

## Font family

```css
body {
  font-family: "Inter", "Segoe UI", sans-serif;
}
```

Provide a fallback stack in case the preferred font is unavailable. Generic families include `serif`, `sans-serif`, `monospace`, `cursive`, and `fantasy`.

Use quotation marks around font names containing spaces.

## Font size and weight

```css
h1 { font-size: 2.5rem; }
p { font-weight: 400; }
strong { font-weight: 700; }
```

- `font-size` sets the text size. Relative units such as `rem` can respect user preferences better than fixed pixel-only sizing.
- `font-weight` commonly ranges from 100 to 900 when the typeface supports those weights; named values include `normal` and `bold`.
- A font may not include every weight; the browser can synthesize one.

## Font style

```css
.quote { font-style: italic; }
```

Common values include `normal`, `italic`, and `oblique`. Use semantic HTML such as `<em>` when the text itself is emphasized; CSS `font-style` controls appearance.

## Line height

```css
body { line-height: 1.6; }
```

`line-height` controls the height of a line box. A unitless value is usually flexible because it scales with the element's font size. Very tight line-height can make paragraphs difficult to read; headings may use tighter values.

## Letter and word spacing

```css
.eyebrow { letter-spacing: .08em; }
.title { word-spacing: .1em; }
```

- `letter-spacing` adjusts spacing between characters.
- `word-spacing` adjusts spacing between words.
- Excessive spacing, particularly in body text, harms legibility.

## Text alignment and decoration

```css
.intro { text-align: center; }
a { text-decoration: underline; text-underline-offset: .2em; }
```

- `text-align`: `start`, `end`, `left`, `right`, `center`, or `justify`.
- Prefer logical `start`/`end` for layouts that may use right-to-left languages.
- `text-decoration` controls underlines, overlines, and line-through decoration.
- Links should remain recognizable as links; do not remove their visual affordance without a clear alternative.

## Text transformation

```css
.label { text-transform: uppercase; }
```

Common values include `uppercase`, `lowercase`, and `capitalize`. This changes visual presentation, not the underlying text. Avoid using it for content where case changes meaning or where screen-reader and copy/paste behavior may confuse users.

## Text shadows

```css
.hero-title { text-shadow: 0 2px 12px rgb(0 0 0 / 25%); }
```

Text shadows can improve contrast over imagery or add subtle depth, but excessive blur or offset can reduce readability. Check actual contrast after applying the effect.

## Web fonts and Google Fonts

A stylesheet can load a hosted web font, for example Google Fonts. Alternatively, declare a locally hosted font with `@font-face`:

```css
@font-face {
  font-family: "Project Sans";
  src: url("/fonts/project-sans.woff2") format("woff2");
  font-weight: 400 700;
  font-style: normal;
  font-display: swap;
}

body { font-family: "Project Sans", sans-serif; }
```

Consider:

- Load only weights and character subsets actually needed.
- Provide a system fallback.
- `font-display: swap` shows fallback text while a font loads, reducing invisible text.
- External font services add network requests and third-party privacy/performance considerations.
- Ensure licenses permit the intended use.

## Fluid typography

`clamp()` can scale text between a minimum and maximum size:

```css
h1 {
  font-size: clamp(2.25rem, 5vw, 5rem);
}
```

The middle value is preferred as the viewport changes, bounded by the minimum and maximum. Test line wrapping at narrow widths and high zoom.

## Interview review

1. Why use a unitless line height? It scales naturally with each element's font size.
2. What does `clamp()` do? Constrains a preferred value between a minimum and a maximum.
3. How do semantic emphasis and italic styling differ? `<em>` conveys emphasis; `font-style: italic` changes appearance.
4. Why provide fallback fonts? The preferred font may fail to load or be unavailable.
5. Why is `font-display: swap` used? It displays fallback text promptly while the web font loads.

## Good practices

- Establish a type scale and a short font stack.
- Prioritize readable body size, line-height, and line length.
- Use bold and uppercase selectively.
- Test responsive wrapping and text zoom.
- Keep links and headings visually distinguishable.
