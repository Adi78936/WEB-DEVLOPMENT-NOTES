# 5.7 Arrays

## Creating and accessing arrays

```js
const grades = [0, 1, 2];
const first = grades[0]; // 0
const last = grades[grades.length - 1];
```

Arrays are zero-indexed, ordered objects. `length` is one greater than the highest present array index; sparse arrays can contain empty slots.

## Modifying arrays

```js
grades[1] = 3;
grades.push(4);      // append; returns new length
const end = grades.pop(); // removes and returns last
grades.unshift(-1);  // prepend
const start = grades.shift(); // removes first
```

`push`, `pop`, `shift`, `unshift`, `splice`, `sort`, and `reverse` mutate the array.

## `slice` and `splice`

```js
const copyPart = grades.slice(1, 3); // new shallow array, end excluded
const removed = grades.splice(1, 2); // mutates; removes 2 items at index 1
```

- `slice(start, end)` returns a shallow portion and does not mutate the source.
- `splice(start, deleteCount, ...items)` changes the original array.

## Combining and searching

```js
const combined = a.concat(b);
items.includes("x");
items.indexOf("x"); // -1 when not found
```

`concat` returns a new shallow array. `includes` uses SameValueZero comparison; `indexOf` uses strict equality and cannot find `NaN`.

## Finding and testing

```js
const item = items.find(value => value.id === id);
const index = items.findIndex(value => value.id === id);
const hasInvalid = items.some(value => !value.valid);
const allValid = items.every(value => value.valid);
```

- `find` returns the first matching value or `undefined`.
- `findIndex` returns the first matching index or `-1`.
- `some` checks whether at least one item matches.
- `every` checks whether every item matches; it returns `true` for an empty array (vacuous truth).

## `map`, `filter`, `reduce`, and `forEach`

```js
const names = users.map(user => user.name);
const active = users.filter(user => user.active);
const total = numbers.reduce((sum, value) => sum + value, 0);
items.forEach(item => console.log(item));
```

- `map` transforms each item into a new array of the same length.
- `filter` returns a new array of matching items.
- `reduce` accumulates items into one value. Supplying an initial accumulator is usually safer, especially for possibly empty arrays.
- `forEach` runs a callback for each present element and returns `undefined`; it is not a transformation and cannot be stopped with `break`.

## Sorting and reversing

```js
const sortedNumbers = [...numbers].sort((a, b) => a - b);
const reversed = [...items].reverse();
```

- `sort()` mutates the array.
- Without a comparator, `sort()` compares string representations, so numbers may sort unexpectedly.
- Use a numeric or domain-appropriate comparator.
- Copy first when the original order must remain unchanged.

## `flat` and `flatMap`

```js
const flattened = [[1], [2, 3]].flat();
const expanded = values.flatMap(value => [value, value * 2]);
```

`flat(depth)` flattens nested arrays to the requested depth (default 1). `flatMap` maps then flattens one level.

## Destructuring and spread

```js
const [first, ...rest] = grades;
const copied = [...grades];
const withMore = [0, ...grades, 4];
```

Array destructuring assigns positions to variables. Spread creates a shallow copy; nested objects are still shared references.

## Mutating vs. non-mutating methods

When updating application state, prefer non-mutating transformations if the framework or architecture relies on reference changes:

```js
const updated = items.map(item =>
  item.id === targetId ? { ...item, active: true } : item
);
```

Modern JavaScript also provides copying methods such as `toSorted()`, `toReversed()`, and `toSpliced()` in supported runtimes. Check target-runtime support before using them.

## Interview review

1. Is `slice` mutating? No; it returns a shallow copy of a portion.
2. Is `splice` mutating? Yes.
3. What does `map` return? A new array of callback results.
4. Why give `reduce` an initial value? It defines the accumulator type and handles empty arrays.
5. Why does `[10, 2].sort()` produce an unexpected order? Default sort compares string forms.
6. How copy an array? `[...array]` or `array.slice()` creates a shallow copy.

## Good practices

- Know whether a method mutates.
- Supply `reduce` initial values and `sort` comparators.
- Use `map` for transformation and `filter` for selection.
- Treat shallow copies carefully when elements are objects.
- Avoid `forEach` when early exit or awaited sequential work is required.
