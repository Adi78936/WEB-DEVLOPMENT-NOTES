# 5.5 Loops

## What is a loop?

A loop repeats a block of code while a condition holds or while it processes items. Choose the loop based on whether you need an index, a value iterator, or an object key.

## `for`

```js
for (let index = 0; index < items.length; index += 1) {
  console.log(index, items[index]);
}
```

The initializer runs once, the condition is checked before each iteration, and the final expression runs after each iteration. A condition that never becomes false can create an infinite loop.

## `while`

```js
let attempts = 0;
while (attempts < 3) {
  attempts += 1;
}
```

Checks the condition before each iteration. Ensure the loop makes progress toward its stopping condition.

## `do...while`

```js
let answer;
do {
  answer = getInput();
} while (!isValid(answer));
```

Runs its body at least once, then checks the condition.

## Nested loops

A loop inside another loop is nested:

```js
for (const row of matrix) {
  for (const cell of row) {
    process(cell);
  }
}
```

If both loops scale with input size, work can grow multiplicatively (for example, `O(n * m)`). Consider the data size and algorithmic complexity.

## `for...of`

Iterates values from an iterable such as an array, string, map, or set:

```js
for (const item of items) {
  process(item);
}
```

Use this when values are needed and an index is unnecessary. `for...of` supports `break` and `continue`.

## `for...in`

Iterates enumerable string property keys, including inherited enumerable keys:

```js
const user = { name: "Ari", active: true };
for (const key in user) {
  if (Object.hasOwn(user, key)) {
    console.log(key, user[key]);
  }
}
```

Do not use `for...in` to iterate array values; use `for...of` or array methods. If enumerating own object properties, `Object.keys()` or `Object.entries()` is often clearer.

## `break` and `continue`

- `break` exits the nearest loop or `switch`.
- `continue` skips the remainder of the current iteration and proceeds to the next.
- A labeled statement can control an outer loop, but labels are rarely needed and can make code harder to follow.

```js
for (const item of items) {
  if (item.disabled) continue;
  if (item.isTarget) break;
  process(item);
}
```

## Loop control and common mistakes

- Check initialization, stopping condition, and update.
- Avoid mutating the collection being iterated unless the behavior is intentional.
- Use `const` for an iteration binding when it is not reassigned.
- Prefer array transformations for concise data transformations, but do not use them when a loop is clearer.

## Interview review

1. Which loop executes at least once? `do...while`.
2. Difference between `for...of` and `for...in`? Values of iterables vs. enumerable property keys.
3. What does `continue` do? Skips the rest of the current iteration.
4. What does `break` do? Exits the nearest loop or switch.
5. How can nested loops affect complexity? They may multiply iteration counts.

## Good practices

- Choose the loop that communicates intent.
- Ensure loop conditions terminate.
- Avoid `for...in` for arrays.
- Consider complexity for nested iteration.
