# 5.10 DOM Manipulation

## What is the DOM?

The **Document Object Model (DOM)** is the browser's object representation of a document. JavaScript can inspect and modify the document through DOM APIs. The DOM is not the HTML source text itself; it is a structured, mutable model.

## DOM tree

Elements are represented in a tree of nodes. Parent/child/sibling relationships describe the structure. Text and comments may also be nodes. `children` returns element children, while `childNodes` can include text and comment nodes.

## Selecting elements

```js
const title = document.getElementById("page-title");
const firstCard = document.querySelector(".card");
const cards = document.querySelectorAll(".card");
```

- `getElementById` finds an element by ID (or `null`).
- `querySelector` returns the first matching element (or `null`).
- `querySelectorAll` returns a static `NodeList` of matching elements.
- Check results before using them when the element may not exist.

## Changing text and HTML

```js
element.textContent = "Preview ready";
```

`textContent` sets plain text. For untrusted or user-provided data, prefer it over `innerHTML`, which parses markup and can create cross-site scripting (XSS) vulnerabilities.

```js
element.innerHTML = "<strong>Ready</strong>";
```

Only assign trusted or properly sanitized HTML to `innerHTML`. Prefer DOM methods and `textContent` when possible.

## Changing styles and classes

```js
element.style.color = "seagreen";
element.classList.add("is-ready");
element.classList.remove("is-loading");
element.classList.toggle("is-open", shouldOpen);
element.classList.contains("is-ready");
```

Use classes for state and keep visual rules in CSS; direct style assignments are best reserved for dynamic values that genuinely need inline styles.

## Creating, appending, and removing elements

```js
const item = document.createElement("li");
item.textContent = "Preprocessing complete";
document.querySelector("ul").append(item);
item.remove();
```

`append()` accepts nodes and strings; `appendChild()` accepts a node and returns it. Prefer `textContent` for inserting text.

## Traversing the DOM

Useful properties include:

- `parentElement`: element parent.
- `children`: element children.
- `firstElementChild`, `lastElementChild`.
- `nextElementSibling`, `previousElementSibling`.
- `closest(selector)`: nearest matching ancestor, including the element itself.

Use semantic selectors and avoid brittle traversal dependent on incidental markup structure.

## Attributes and properties

```js
const input = document.querySelector("input");
input.getAttribute("aria-label");
input.setAttribute("aria-label", "Search");
input.removeAttribute("disabled");
```

HTML attributes initialize/configure elements; DOM properties represent current object state. For example, an input's `value` property reflects its current value, while its `value` attribute is related to the initial/default value. Use the appropriate interface.

## Data attributes

HTML:

```html
<button data-action="remove" data-item-id="42">Remove</button>
```

JavaScript:

```js
button.dataset.action; // "remove"
button.dataset.itemId; // "42"
```

Dataset values are strings. Parse and validate them before treating them as numbers or other types. Do not store secrets in HTML attributes.

## Interview review

1. DOM vs. HTML source? DOM is the parsed, mutable object model; source is document markup.
2. `querySelector` vs. `querySelectorAll`? First match vs. static collection of matches.
3. Why prefer `textContent` for user input? It inserts text rather than parsing it as HTML.
4. How do you append an element? Create it, set safe content, then use `append()` or `appendChild()`.
5. What is the difference between `children` and `childNodes`? Element children vs. all node types.
6. What does `closest()` do? Finds the nearest matching ancestor or the element itself.

## Good practices

- Avoid injecting untrusted strings with `innerHTML`.
- Check possibly missing query results.
- Use classes for visual state and semantic attributes for meaning.
- Prefer `textContent` for plain text.
- Avoid unnecessary repeated DOM reads/writes in performance-sensitive loops.
